# Invitación digital de boda — Flor & Samu

Sitio web estático (HTML/CSS/JS) con varias páginas:

- `index.html` — Portada, historia, programa, dress code, regalos.
- `ubicacion.html` — Lugar del evento, mapa y cómo llegar.
- `mensaje.html` — Confirmar asistencia, mensaje y alergenos (envío por WhatsApp/email).
- `encuesta.html` — Encuesta para invitados con resultados.
- `preboda.html` — Información de la preboda y confirmación.

## Personalizar

Edita el objeto `CONFIG` al inicio de `script.js` (nombres, fecha, teléfono, email, dirección, mapa).

## Probar localmente

Abre `index.html` en el navegador o sirve la carpeta:

```bash
npx serve .
```

## Publicar

Sube la carpeta a cualquier hosting estático (GitHub Pages, Cloudflare Pages, Netlify). No requiere backend.
